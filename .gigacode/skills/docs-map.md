# Карта документов contactApi

Читать по необходимости, не подгружать всё сразу.

## Цикл (что сдаём на этой неделе)

Для каждой новой задачи создавай пакет  с `task-NN`. в папке  `sdd`.
В ней и создавай `spec.md`.
после приступай к задаче после отметь что она выполненна.
после выполнения обновит основую спеку всего проекта в папке `sdd`. файл `index.md`.

| Файл | Когда |
|---|---|
| `sdd/README.md` | метод SDD, какой цикл активен |
| `sdd/cycle-NN.md` | цель, скоуп, доска задач, DoD, демо, вне скоупа |
| `sdd/task-NN/spec.md` | спека одной задачи; без файла код не пишем |

## Система (как устроен продукт)

| Файл | Когда |
|---|---|
| `architecture/README.md` | оглавление |
| `architecture/product.md` | вход/выход, ценность, кто клиент |
| `architecture/system.md` | поток «откуда куда», запретные стрелки, порты |
| `architecture/diagram.html` | та же схема визуально |
| `architecture/contracts.md` | JSON, эндпоинты, статусы (черновик, пока не заморожен) |
| `architecture/services.md` | зоны, стек, что модуль не делает |
| `architecture/team.md` | кто владелец модуля |
| `architecture/task-guide.md` | как формулировать задачу |
| `architecture/backlog.md` | идеи вне текущего цикла |
| `architecture/agent-context.json` | снимок для агента, не для команды |

## Выдача

| Файл | Когда |
|---|---|
| `tasks/README.md` | нумерация, кто что делает |
| `tasks/<Имя>.md` | выдача человеку; обязана ссылаться на `sdd/task-NN/spec.md` |

Порядок чтения перед кодом: активный цикл → `sdd/task-NN/spec.md` → `product.md` → `system.md` → `contracts.md`. `services.md` / `team.md` — если нужна зона или исполнитель.
