# Как пишем задачи разработчикам

Каждая задача должна быть исполняемой без чтения этого чата. Контекст — папка `architecture/`.

## Обязательные поля

```text
Номер: task-NN (сквозная нумерация, см. tasks/README.md)
Модуль: rest-core | ai-core | tg-bot | devops | qa
Исполнитель:
Связанные: (ID других задач)
Тип: feature | spike | bug | chore
Цель: одно предложение, зачем это пользователю/системе
Контекст: ссылки на architecture/*.md
Граница: что меняем / что трогать нельзя
Контракт: эндпоинт + JSON или «без API»
DoD:
  - [ ] код в своём модуле
  - [ ] поведение совпадает с contracts.md (если API)
  - [ ] секреты только через env
  - [ ] коротко как проверить (curl / сценарий бота)
Вне скоупа: явно
```

## Правила лида

1. Не смешивать Telegram и LLM в одной задаче.
2. Не просить rest-core «сходить в нейросеть» — только в ai-core.
3. Не просить ai-core «сохранить в БД».
4. Не вставлять ключи ProxyAI в формулировку задачи.
5. Сначала контракт, потом две реализации по разные стороны Feign.
6. Илью не назначаем.
7. Бухгалтерия Андрея — не в dev-бэклог contactApi.

## Готовые формулировки границ (копировать в задачу)

**rest-core:** принимаешь HTTP, валидируешь, ходишь в ai-core, собираешь публичный JSON. ProxyAI не вызываешь.

**ai-core:** принимаешь внутренний HTTP от rest-core, ходишь только в ProxyAI, возвращаешь структурированный ответ. PostgreSQL нет.

**tg-bot:** пользовательский ввод → rest-core → сообщение в чат. ai-core не вызываешь.

**devops:** порты, env `PROXYAI_BASE_URL` / `PROXYAI_API_KEY` / `PROXYAI_MODEL`, сеть так, чтобы ai-core был недоступен снаружи.

## Порядок первого среза (эпик EPIC-1)

1. devops: каркас запуска трёх сервисов + env ProxyAI.
2. contracts freeze v0 (лид + архитектор) — этот файл уже черновик.
3. ai-core: клиент ProxyAI + internal `/internal/v1/extract`.
4. rest-core: public `/api/v1/contacts/search` + Feign на ai-core.
5. tg-bot: команда «название организации» → rest-core.
6. qa: контрактные тесты + один e2e через бота или curl.

Пока 3–5 не стабилизированы, не плодить задачи на филиалы, ИНН и биллинг.
