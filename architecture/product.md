# Продукт

**contactApi** — Java REST backend для извлечения контактных данных организаций, ресторанов и компаний на территории РФ.

Клиент отправляет **название организации**. Сервис возвращает **валидный структурированный JSON** с адресом и телефонами.

## Зачем существует

- Не парсить вручную гео-справочники.
- Не покупать тяжёлые коммерческие платформы ради «название → телефон + адрес».
- Устойчивость к опечаткам, разговорным сокращениям и неправильному регистру (NLP / LLM).
- Предсказуемая JSON-схема под POJO (Jackson / Gson).
- Простое подключение из Spring Boot / Micronaut / Quarkus через WebClient или RestTemplate.

## Вход

Минимум: свободный текст с названием организации.

Допустимо позже (не блокирует первый срез): город, регион, уточнение филиала.

## Выход

Строго типизированный JSON:

- нормализованное название;
- адрес;
- список телефонов;
- служебные поля (уверенность, статус, причина, если не нашли).

География: **только РФ**.

## Кто потребитель API

| Клиент | Как ходит |
|---|---|
| `tg-bot` | внутренний клиент команды, только в `rest-core` |
| сторонние web/mobile | публичный клиент, только в `rest-core` |

Клиенты **не** ходят в `ai-core` и **не** ходят в ProxyAI.
