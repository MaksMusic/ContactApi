task-06. Олег.
Модуль: tg-bot.

Зачем.
Чтобы бот потом брал токен из настроек, а не из кода. 
Сам бот в телеграме пока не пишем.

Что сделать.
Класс BotProperties.
Поля BotProperties: token, username.
token это токен бота.
username это имя бота.
Значения брать из переменных окружения: TELEGRAM_BOT_TOKEN и TELEGRAM_BOT_USERNAME.
В application.properties ключи: telegram.bot.token и telegram.bot.username.
Настроить логи: time, level, logger, message.
Библиотеку телеграма и ответы на сообщения не подключать.
Токен в git не класть.

Готово когда.
Класс BotProperties есть, поля token и username на месте.
Настройки читаются из env.
Приложение запускается.
Есть коммит.
