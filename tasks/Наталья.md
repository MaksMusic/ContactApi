task-07. Наталья.
Модуль: qa.

Зачем.
Чтобы заранее было видно, что проверять, когда появится API. Живые автотесты пока не пишем, эндпоинтов ещё нет.

Что сделать.
Создать папку qa.
Написать короткий список проверок.
Проверка 1: GET /internal/v1/health, в ответе поле status.
Проверка 2: POST /api/v1/contacts/search без поля query, должна быть ошибка.
Проверка 3: POST /api/v1/contacts/search с полями query и city, в ответе поля status, organizationName, address, phones.
Проверка 4: в address проверить поля full, city, street.
Проверка 5: бот отвечает текстом с названием, адресом и телефоном.
Пометить, что API ещё не готово.

В примере запроса тело такое.
Поля запроса SearchRequest: query, city.
Поля ответа SearchResponse: status, organizationName, normalizedQuery, address, phones, confidence, message.
Поля адреса AddressDto: full, country, city, street, building, postalCode.

Готово когда.
Папка qa есть.
Список проверок и пример запроса на месте.
В примере видны имена полей.
Есть коммит.
