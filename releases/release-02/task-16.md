Зачем.
Если человек пришлёт пустой запрос, ему нужна понятная ошибка. Контроллер поиска ещё не пишем. Нужен только класс данных для ошибки.

Что сделать.
1. В rest-core создай класс ErrorResponse в пакете dto.
2. Поля только такие:
code — строка, например QUERY_REQUIRED
message — строка, человеческое пояснение
3. Контроллер, поиск, базу не делать.

Как проверить.
Класс есть, два поля на месте.
mvn -f rest-core/pom.xml compile

Готово когда.
ErrorResponse с полями code и message.
Проект собирается.
Есть коммит в rest-core.
